Pathfinder Visualizer:

A small project where I explore how pathfinding algorithms work through an interactive grid.
I built this project to understand how algorithms like A* and Dijkstra actually find their way from a starting point to a destination. 
Instead of just reading about them, I wanted to see how they behave visually, compare their results, and experiment with different obstacles. 

What can you do with it?
- Visualize A*, Dijkstra, BFS, and Greedy Best-First Search.
- Draw walls and obstacles directly on the grid.
- Add mud tiles to see how weighted terrain affects pathfinding.
- Move the start and destination points.
- Generate random mazes.
- Adjust the visualization speed.
- View statistics such as explored nodes, path length, and total cost.

Built with:
- HTML
- CSS
- JavaScript

No frameworks or additional installations are required.

How to run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Start experimenting with the grid and algorithms.
